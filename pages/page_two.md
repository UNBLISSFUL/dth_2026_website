## Disadvantages of Open Source

Everyone having access to open source software is a big advantage, but can also be a big disadvantage as it could certainly lead to security issues. Open source vulnerabilities might be exploited to gain access to a multitude of things. An example would be XZ Utils, where a backdoor was discovered, revealing hidden malicious code. In this case the community-driven nature of open source projects  was utilized to gain access and trust to implement small changes eventually implementing harmful code (Carter, 2024).This beckons the question of, in what capacity projects should be managed and whether it’s viable for a single person to manage an evolving project on their own time. It also leads to a question of whether the project can receive funding if needed.

An example of a former open source project that chose to change to closed-source is the personal media server Emby. As for the evolution of Emby per sross44’s (2024) blog post, the project started as an open source project and gained a loyal community. As they continued growing, it eventually prompted a change, making the shift from open source to closed source to allow the developer team to maintain greater control. This change also included a subscription, which is one way to get some funding for the software. This change led to community members forking the last open source release and creating Jellyfin (Ghosh, 2026), in true open source fashion.

As projects may become unmanageable, support is not always guaranteed either where most closed-source products likely provide support in one way or another. Additionally, using and modifying open source projects might pose a legal risk concerning the understanding of licensing terms.
